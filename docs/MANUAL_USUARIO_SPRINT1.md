# Manual do Usuário - Sprint 1

## Iniciar uma solicitação

Acesse a página inicial e clique em `Solicitar cartão` ou `Começar solicitação`.

## Etapa 1 - Escolher cartão

Escolha uma das opções apresentadas:

- Cartão DM
- Cartão Loja Física
- Cartão Loja Digital

Clique em `Continuar`.

## Etapa 2 - Informar dados

Preencha:

- nome completo;
- CPF;
- telefone;
- e-mail;
- CEP.

### Cartão Loja Física

Clique em `Buscar lojas` depois de preencher o CEP.

O sistema identifica o estado e mostra somente lojas parceiras cadastradas naquele estado.

Escolha uma loja antes de enviar a solicitação.

## Etapa 3 - Resultado

Após o envio, o sistema mostra:

- número da solicitação;
- cartão escolhido;
- status inicial;
- loja escolhida, quando aplicável.

Na Sprint 1, as solicitações seguem inicialmente com o status `Em análise`.
